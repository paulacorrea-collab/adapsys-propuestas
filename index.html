Cómo obtener el Client ID de Google

  1. Ve a console.cloud.google.com
  2. Crea un proyecto nuevo (ej: "Adapsys Propuestas")
  3. APIs y servicios → Biblioteca → activa Google Slides API y Google Drive API
  4. APIs y servicios → Pantalla de consentimiento OAuth → tipo "Externo", completa nombre y email
  5. Credenciales → Crear credenciales → ID de cliente OAuth 2.0
  6. Tipo: Aplicación web
  7. Orígenes autorizados: agrega http://localhost:3000 y tu dominio de Vercel
  8. Copia el ID de cliente y pégalo aquí
